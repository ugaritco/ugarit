## About Ugarit

Ugarit is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Ugarit takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://ugarit.com/docs/routing).
- [Powerful dependency injection container](https://ugarit.com/docs/container).
- Multiple back-ends for [session](https://ugarit.com/docs/session) and [cache](https://ugarit.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://ugarit.com/docs/eloquent).
- Database agnostic [schema migrations](https://ugarit.com/docs/migrations).
- [Robust background job processing](https://ugarit.com/docs/queues).
- [Real-time event broadcasting](https://ugarit.com/docs/broadcasting).

Ugarit is accessible, powerful, and provides tools required for large, robust applications.

## Learning Ugarit

Ugarit has the most extensive and thorough [documentation](https://ugarit.com/docs) and video tutorial library of all modern web application frameworks, making it a breeze to get started with the framework.

In addition, [Laracasts](https://laracasts.com) contains thousands of video tutorials on a range of topics including Ugarit, modern PHP, unit testing, and JavaScript. Boost your skills by digging into our comprehensive video library.

You can also watch bite-sized lessons with real-world projects on [Ugarit Learn](https://ugarit.com/learn), where you will be guided through building a Ugarit application from scratch while learning PHP fundamentals.

## Agentic Development

Ugarit's predictable structure and conventions make it ideal for AI coding agents like Claude Code, Cursor, and GitHub Copilot. Install [Ugarit Boost](https://ugarit.com/docs/ai) to supercharge your AI workflow:

```bash
composer require ugarit/boost --dev

php scribe boost:install
```

Boost provides your agent 15+ tools and skills that help agents build Ugarit applications while following best practices.
